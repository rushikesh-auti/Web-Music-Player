# Web Music Player

A sleek and responsive web-based music player built using HTML, CSS, and JavaScript.  
The application allows users to play audio tracks directly in the browser with an intuitive interface and smooth playback controls.

---

## Project Description

This project implements a browser-based music player that allows users to play, pause, and navigate between songs. It features a modern UI design and interactive controls for managing music playback.

The project focuses on implementing JavaScript functionality for audio control, dynamic UI updates, and responsive layout design.

---

## Features

- Play and pause music
- Next and previous track controls
- Display of current track name
- Progress bar showing playback progress
- Seek functionality by clicking the progress bar
- Responsive and modern user interface

---

## Technologies Used

- HTML   
- CSS
- JavaScript 

---

## Learning Outcomes

- Working with the JavaScript Audio API
- Handling events for media playback
- DOM manipulation for dynamic UI updates
- Designing responsive interfaces using CSS
